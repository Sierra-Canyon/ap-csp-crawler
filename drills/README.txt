drills/: starter programs for class.

Each folder is a small program that already runs. Your sheet tells you which one to copy and
what to change. Copy it into practice/ in your WORK repository. Do not edit it here.

From the root of your work repository:

    cp -r ../apcsp-2026-2027-crawler-USERNAME/drills/no_parameters practice/
    cd practice/no_parameters
    dotnet run

Put your own GitHub username where it says USERNAME.
